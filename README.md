# Alhambra Film — Production Assets

This repository contains the prepared assets and production documents for the Alhambra documentary motion film.

## Contents

- `audio/` — compressed narration, two background music options, and the supplied muwashah reference.
- `storyboards/` — eight storyboard reference images with English filenames.
- `docs/alhambra_agent_production_brief.md` — production and creative direction brief.
- `docs/alhambra_code_reference.md` — technical code reference and implementation patterns.
- `ASSET_INVENTORY.md` — source mapping, processing notes, and file sizes.

## Media preparation

All files are below 30 MB individually. The original WAV music files were converted to 192 kbps MP3, and the narration was converted to 160 kbps MP3. The supplied muwashah M4A was already below the limit and was retained as provided.

## Rights note

The supplied muwashah recording appears to be a commercial artist recording. Verify that you have permission to redistribute it publicly before publishing this repository or using it in a public film.
